# HEIT-DSS 

**企业决策支持系统 / enterprise-decision-support-system**

> 让企业战略决策有史可依，有据可查。

---

## 这是什么？

HEIT-DSS 是一个面向企业或个人战略决策的智能支持系统。

传统战略咨询依赖专家经验，周期长、成本高、难以规模化。通用大模型虽然能快速生成建议，但存在幻觉、缺乏依据、无法验证等问题。

HEIT-DSS 的核心思路是：**从百年商业史中自动提取可复用的“条件-策略”规则，结合跨学科理论进行解释与迁移，为用户输出有历史案例支撑、可追溯、可验证的战略建议。**

---

## 核心能力

- **条件策略匹配**：从历史案例库中自动拟合“满足什么条件 → 采用什么策略 → 成功率如何”的规则，而非简单检索相似案例。
- **跨行业迁移**：不局限于单一行业，能从糖果业的“低端颠覆”迁移到新能源车的市场切入策略。
- **可解释输出**：每条建议附带历史案例引用、理论依据、适用边界与风险提示。
- **自迭代进化**：系统根据用户反馈与新增案例，自动优化条件组与策略库，越用越准。

## 核心技术点

### 1. 条件策略匹配器

不直接检索“相似案例”，而是从案例中归纳出**可复用的条件组**：

- **元条件**：宽泛的行业/市场特征（如“市场集中度高”“技术变革缓慢”）
- **附加条件**：细分情境特征（如“存在被忽视的低端市场”“客户价格敏感”）

条件组采用**预定义ID + 序号组合**存储，支持精确匹配、相似度控制、自动升格。

### 2. 后验验证机制

每条拟合出的条件组，需通过随机抽样案例的后验检验：

- 从案例库中随机抽取未参与归纳的案例
- 检验其是否满足条件组，且采用对应策略
- 只有成功率超过阈值，条件组才被采纳

### 3. Harness Engineering
系统不依赖模型训练或微调，而是通过**提示词编排 + 多智能体协作 + 结构化知识库**，将通用大模型的能力引导到垂直决策场景。
